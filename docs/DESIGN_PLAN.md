# 리디북스 페이퍼 프로 날씨 대시보드 설계서 (v2)

## 1. 타겟 기기 및 실행 구조 (리디북스 겸용)
- **대상 기기:** Ridibooks Paper Pro (`RBPP1`, Android 4.4.2 / API 19, `armeabi-v7a`, `1404 × 1872` / 320 dpi E-Ink)
- **서재 책 아이콘 방식의 실행/종료 흐름:**
  1. **서재 등록용 트리거 EPUB (`날씨 대시보드.epub`)**: 전용 표지 이미지(`library_book_cover_sample.png`)를 포함한 더미 EPUB 파일을 `/sdcard/Books/`에 배치하여 리디북스 **서재에 일반 책처럼 아이콘으로 표시**합니다.
  2. **백그라운드 감시 서비스 (루트 권한 활용)**: 기기 부팅 시 자동 실행되는 경량 서비스가 리디북스 뷰어(`com.ridi.paper`)에서 해당 트리거 EPUB을 여는 순간을 감지하여 **날씨 대시보드 앱을 즉시 전면 실행**합니다.
  3. **복귀(닫기)**: 대시보드 우측 상단의 **[닫기]** 버튼 또는 기기의 물리 뒤로가기 버튼을 누르면 대시보드와 더미 뷰어를 함께 닫아 **리디북스 서재로 바로 복귀**합니다.

## 2. 확정된 요구사항 및 기술 설계

### A. Wi-Fi 기반 현재 위치 자동 인식 (하이브리드 방식)
- **하드웨어 제약:** 리디북스 페이퍼 프로에는 GPS 모듈, 셀룰러, Google Play Services가 없어 안드로이드 기본 위치 서비스(`NETWORK_PROVIDER`)를 사용할 수 없습니다.
- **해결 방안:** Wi-Fi가 연결된 상태에서 **IP 기반 지오로케이션 API**로 현재 공용 IP의 위도·경도 및 지역명을 자동 인식해 기본 지역으로 설정합니다 (`(자동)` 표시).
- **오차 보완:** 통신사 라우팅에 따라 IP 위치가 실제 행정구역과 시/구 단위로 다를 수 있으므로, 상단 `[지역]` 버튼에서 **자동 감지 재시도**와 **수동 도시 검색·고정**을 모두 지원합니다.

### B. 자동 갱신(30분) · 앱 자체 화면 유지 타이머(1~12시간) · 밝기 조절
- **30분 단위 자동 갱신:** 대시보드가 켜져 있는 동안 Wi-Fi 연결 상태를 확인하여 **30분마다** 날씨·대기질·자외선지수를 자동 갱신합니다. (E-Ink 잔상 방지를 위한 주기적 전체 화면 리프레시 포함)
- **기기 절전 설정과 독립된 화면 유지 타이머:**
  - 기기 시스템의 절전 시간 설정을 따르지 않고, 앱 실행 중 `FLAG_KEEP_SCREEN_ON` / WakeLock으로 화면을 유지합니다.
  - 상단 `[설정]` 화면에서 **화면 유지 시간을 기본 1시간 ~ 최대 12시간** 범위로 직접 지정할 수 있으며, 지정 시간이 경과하면 화면 유지를 해제해 배터리를 보호합니다.
- **디스플레이 밝기(프론트라이트) 조절:**
  - `[설정]` 화면 내에 **화면 밝기 슬라이더**를 제공하여 대시보드 내에서 프론트라이트 밝기를 즉시 조절·저장할 수 있습니다. (개발 시 Paper Pro의 밝기 제어 인터페이스 `/sys/class/backlight` 또는 `Settings.System` 경로 검증 적용)

### C. 날씨·환경 데이터 및 자외선지수
- **API 구성:** Open-Meteo Forecast + Air Quality API (무료·API 키 불필요, Android 4.4.2용 `TLSSocketFactory` + `OkHttp 3.12.x` 적용)
- **메인 화면 필수 표시 항목:**
  - 현재 시간 / 날짜 / 일출·일몰
  - 현재 지역명(`(자동)` 또는 수동) + 최근 갱신 시각 + Wi-Fi 상태
  - 현재 기온, 날씨 아이콘·상태, 체감온도, 강수확률
  - **어제와의 비교** (`past_days=1` 기반 어제 동시간대 기온 대비 증감) 및 **당일 최고·최저 기온**
  - **5대 환경 지표 카드:** 미세먼지(PM10), 초미세먼지(PM2.5), **자외선 지수(UV)**, 습도(%), 풍속(m/s · 풍향)
  - **시간별 날씨** (3시간 간격 8슬롯) 및 **주간 날씨** (7일 예보 + 온도 범위 막대)

## 4. 다국어(한국어/영어) · 뉴스 대륙/국가 선택 · GitHub 공개 설계

### A. 앱 언어 설정 (`language`: `"ko"` | `"en"`)
- **설정 위치**: `[설정]` 다이얼로그 내 `언어 / Language` 선택 (`한국어`, `English`)
- **적용 범위**:
  - **UI 텍스트**: 상단 버튼(`지역/Region`, `설정/Settings`, `새로고침/Refresh`, `닫기/Close`), 날짜·요일 포맷, 음력/일출·일몰 라벨, 현재 날씨 상태 및 5대 환경 지표 등급, 시간별/주간 예보, 하단 페이지네이션 및 상태바
  - **오늘의 명언**:
    - `ko`: 영문 명언 API 수신 후 한국어 번역 출력 (실패 시 한국어 폴백 명언 풀 사용)
    - `en`: 영문 명언 원문 그대로 출력 (실패 시 영문 폴백 명언 풀 사용)

### B. 뉴스 대륙/국가 선택 (`newsContinent`, `newsCountry`)
- **설정 구조**: `[설정]` 다이얼로그에서 대륙 → 국가 계층 또는 대륙별 그룹 목록으로 선택
  - **아시아 · 태평양 (Asia-Pacific)**: 대한민국 (`KR`), 일본 (`JP`), 싱가포르 (`SG`), 호주 (`AU`), 인도 (`IN`), 대만 (`TW`)
  - **북미 (North America)**: 미국 (`US`), 캐나다 (`CA`)
  - **유럽 (Europe)**: 영국 (`GB`), 독일 (`DE`), 프랑스 (`FR`), 이탈리아 (`IT`), 스페인 (`ES`)
- **피드 URL 매핑**:
  - 선택한 국가(`gl`)와 앱 언어(`hl`) 또는 해당 국가/영문 피드(`ceid`)를 조합하여 Google News RSS(`https://news.google.com/rss?hl=...&gl=...&ceid=...`)를 동적으로 호출
  - 예: 한국+한국어(`hl=ko&gl=KR&ceid=KR:ko`), 미국+영어(`hl=en-US&gl=US&ceid=US:en`), 일본+영어(`hl=en&gl=JP&ceid=JP:en`) 또는 일본+한국어(`hl=ko&gl=JP&ceid=JP:ko` / 미지원 국가 시 영문/현지 피드 폴백) 검증 후 적용

### C. GitHub 공개 및 EPUB 배포 준비
- **배포 구성물**:
  - 트리거 EPUB 파일 (`날씨 대시보드.epub` — 리디북스 서재 배치용)
  - 빌드된 APK (`app-debug.apk` 또는 `app-release.apk`)
  - `README.md` 설치·권한·사용 가이드 (한국어/영어 병기 고려)
