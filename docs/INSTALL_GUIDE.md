# 리디북스 페이퍼 프로(Ridibooks Paper Pro) 설치 가이드

리디북스 페이퍼 프로와 같은 커스텀 전자책 리더기는 일반 스마트폰과 달리 **파일 탐색기에서 `.apk` 파일을 직접 눌러 설치하는 기능이 제한**되어 있습니다.  
따라서 아래 순서대로 PC에서 **USB 케이블(`adb`)을 이용해 1회만 설치**해 두면, 이후에는 서재에서 책(`WeatherDashboard.epub`)을 여는 것만으로 대시보드를 바로 실행할 수 있습니다.

> [!NOTE]
> **지원 기기 안내**  
> 현재 버전은 **리디북스 페이퍼 프로(`1404 × 1872`, Android 4.4.2)**에 최적화되어 있습니다.  
> 다른 기기나 해상도로 커스텀할 경우 **해상도·화면 비율 차이로 인한 UI/터치/대기화면 문제**가 발생할 수 있습니다.

---

## 0. 사전 준비물
1. **리디북스 페이퍼 프로** (루팅 / SuperSU 적용 상태 권장)
2. **Windows PC** 및 데이터 전송 가능한 **USB 케이블**
3. 이 저장소의 파일 2개:
   - 대시보드 앱 설치 파일: `app-debug.apk` (`app/build/outputs/apk/debug/app-debug.apk`)
   - 서재 실행용 트리거 책: `WeatherDashboard.epub` (저장소 루트)

---

## 1단계: PC에 ADB 도구 준비하기
1. Google 공식 **Android SDK Platform-Tools (Windows용)** 를 다운로드해 원하는 폴더(예: `C:\platform-tools`)에 압축을 풉니다.  
   - 다운로드: `https://developer.android.com/tools/releases/platform-tools`
2. 압축을 푼 폴더(`C:\platform-tools`)에 `app-debug.apk`와 `WeatherDashboard.epub` 파일을 함께 복사해 두면 명령어 입력이 가장 편합니다.

---

## 2단계: 페이퍼 프로와 PC 연결 확인
1. 페이퍼 프로의 **설정 → 개발자 옵션**에서 **USB 디버깅**을 켭니다.  
   *(이미 커스텀 펌웨어/루팅이 되어 있다면 대부분 켜져 있습니다.)*
2. USB 케이블로 페이퍼 프로와 PC를 연결합니다.  
   - 기기 화면에 **"USB 디버깅을 허용하시겠습니까?"** 팝업이 뜨면 **"항상 허용"** 체크 후 **확인**을 누릅니다.
3. PC에서 `C:\platform-tools` 폴더의 주소창에 `cmd` 또는 `powershell`을 입력해 터미널을 연 뒤, 아래 명령어를 입력합니다.
   ```powershell
   .\adb.exe devices
   ```
4. 목록에 기기 시리얼 번호 옆 `device`가 표시되면 연결 성공입니다.
   ```text
   List of devices attached
   PP1A1HA178296   device
   ```
   - 만약 `unauthorized`가 뜨면 페이퍼 프로 화면의 USB 디버깅 허용 팝업을 확인해 주세요.

---

## 3단계: 대시보드 앱(APK) 설치
터미널에서 아래 명령어를 입력해 앱을 설치합니다.
```powershell
.\adb.exe install -r app-debug.apk
```
- 화면에 `Success`가 출력되면 설치 완료입니다.

---

## 4단계: 트리거 EPUB 파일을 서재에 넣기
아래 명령어로 `WeatherDashboard.epub` 파일을 리디북스 서재 폴더(`/sdcard/Books/`)로 복사합니다.
```powershell
.\adb.exe push WeatherDashboard.epub /sdcard/Books/WeatherDashboard.epub
```
*(또는 PC 탐색기에서 페이퍼 프로 내부 저장소의 `Books` 폴더로 직접 복사해도 동일합니다.)*

---

## 5단계: 서재에서 실행 및 최초 1회 권한 허용
1. 페이퍼 프로에서 **리디북스 서재**를 열면 **`날씨 대시보드`** 책이 추가되어 있습니다.
2. **`날씨 대시보드`** 책을 터치해 엽니다.
3. 최초 실행 시 **SuperSU 루트 권한 요청** 팝업이 뜨면 **허용(Grant)** 을 누릅니다.  
   *(기기의 백그라운드 서재 감시, `[닫기]`로 서재 복귀, 대기화면 연동 기능에 필요합니다.)*
4. 잠시 후 날씨 대시보드 화면으로 자동 전환되면 모든 설정이 완료된 것입니다!

> [!TIP]
> **책을 열어도 대시보드로 바로 넘어가지 않는 경우**  
> 앱 설치 직후 백그라운드 감시 서비스(`LibraryWatcherService`)가 아직 시작되지 않았을 수 있습니다. 페이퍼 프로를 **1회 재부팅**하면 부팅 시 자동 실행되어 이후부터는 서재에서 책만 열어도 즉시 전환됩니다.

---

## 6단계: 기본 사용법 요약
- **페이지 전환:** 기기 좌우 물리 페이지 넘김 버튼 또는 화면 하단 `◀ / ▶` 터치
- **설정 / 지역 변경:** 우측 상단 `[지역]`, `[설정]`, `[새로고침]`, `[닫기]` 버튼 사용
- **서재로 돌아가기:** 우측 상단 `[닫기]` 또는 기기 뒤로가기 버튼
